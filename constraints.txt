# toolchain is pinned and upgraded deliberately.

# only the tools that decide whether a build passes.
#
# Install:  pip install -e ".[dev]" -c constraints.txt
# Upgrade:  bump a pin here, run the suite locally, commit the version bump
#           together with whatever it broke.
